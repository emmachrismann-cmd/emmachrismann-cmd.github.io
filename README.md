# Portfolio d'Emma Chrismann

Site statique HTML/CSS/JS pour le portfolio professionnel d'Emma Chrismann.

## Structure
- `index.html` : contenus et sections du site
- `css/styles.css` : identité visuelle et responsive
- `js/main.js` : menu mobile
- `assets/images/` : portrait et images générales
- `assets/projects/` : visuels des réalisations
